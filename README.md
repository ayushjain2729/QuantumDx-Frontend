# QuantumDx — Quantum-Enhanced Clinical Intelligence Platform

QuantumDx is an advanced, spatial-aesthetic clinical intelligence and decision support platform powered by hybrid quantum-classical machine learning algorithms (QSVM with 4-qubit ZZ-feature mapping). It provides real-time risk grading, explainable biomarker attribution (SHAP), dynamic baseline benchmarking, and automated EHR-ready report generation.

## 🌟 Key Features

- **Fluid Astra-Inspired Spatial Interface**: Built with Three.js ambient particle fields, spring-physics cards, animated counting typography, and fluid morphing gradient glow orbs.
- **Hybrid Quantum-Classical Diagnostic Engine**: Dual-phase QSVM classifier achieving **0.993 ROC-AUC** for non-invasive risk detection.
- **Patient Cohort & Volunteer Screening**: Live cohort management with instant search, multi-factor risk categorization, and deep clinical inspection.
- **Biomarker Explainability**: Interactive SHAP-based feature importance breakdown covering glucose, cardiac strain, and genomic biomarkers.
- **Comprehensive Benchmarking**: Real-time cross-validation comparing QuantumDx against Random Forests, Deep Neural Networks, and standard Logistic Regression baselines.
- **Commercial Intelligence & ROI Calculator (in Rs / ₹)**:
  - Transparent institutional tiers in Indian Rupees (₹ / INR): Academic (₹3,999/mo), Diagnostic Center (₹14,999/mo), Enterprise (₹49,999/mo).
  - Live interactive hospital savings & ROI calculator.
  - ABDM (Ayushman Bharat Digital Mission) compliance readiness & DPDP Act 2023 sovereign data architecture.
  - Printable official Pro-Forma Quotation generator.
- **Clinical Report Center**: PDF and EHR-ready exportable clinical summaries with one-click print optimization.

## 🚀 Tech Stack

- **Framework**: React 18, Vite 8
- **Visuals & 3D**: Three.js (Spatial Point Field)
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Styling**: Vanilla CSS with curated dark glassmorphism and quantum-signal accents

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/ayushjain2729/QuantumDx-Frontend.git

# Navigate into directory
cd QuantumDx-Frontend

# Install dependencies
npm install

# Start local development server
npm run dev
```

## 📦 Production Build

```bash
# Generate production bundle
npm run build

# Preview build locally
npm run preview
```
